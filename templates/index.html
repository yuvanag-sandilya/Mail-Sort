How it works

1
Text Vectorization

Your email is converted into numerical features using TF-IDF (Term Frequency-Inverse Document Frequency), capturing the importance of each word.

2
Classification

A Logistic Regression model trained on labeled email data predicts the priority class based on learned patterns.

3
Signal Detection

Key phrases and words are highlighted to explain why the model classified the email the way it did.

Stack: Python · Flask · scikit-learn · Docker

Model: Logistic Regression with TF-IDF features (bigrams)
